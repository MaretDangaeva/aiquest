# Источники иллюстраций

- `ai_cosmic_cat.webp`, `ai_sky_city.webp`, `ai_mars_colony.webp`, `ai_capybara_cafe.webp` — части новой иллюстрации, созданной генеративным инструментом по запросу для этого квеста. Это **отдельные сцены без элементов интерфейса**, используемые как примеры ИИ-изображений.
- `real_cat.webp`, `real_coffee.webp`, `real_astronaut.webp`, `real_rocket.webp` — реальные фотографии, перенесённые из предыдущей версии. Их лицензия и происхождение **не были независимо подтверждены**; перед публичным коммерческим размещением необходимо заменить их на фотографии с подтверждёнными правами либо проверить условия использования.
- Луня — встроенный оригинальный SVG-персонаж. Вторая часть задания с промптом использует CSS-изменение освещения, а не новую генерацию ИИ.
- Официальный логотип Тетрики подключён в `index.html` по URL, который предоставил заказчик. Локальный `tetrika-logo.svg` — лишь резервное стилизованное изображение, не оригинальный брендовый файл.
