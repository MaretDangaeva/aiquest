# 🎁 Снежная почта — командная настольно-карточная игра

Браузерная игра для **2–10 участников** (5–9 классы) в новогодней тематике, с интеграцией понятий из курса **«Искусственный интеллект»**. Продолжительность: 15–25 минут. Вместо викторин — общая доска, уникальные роли, карточки действий и ходы по очереди.

## Как играть

1. Преподаватель открывает `index.html` (или адрес GitHub Pages) и нажимает **«Создать игру»**.
2. Преподаватель копирует одну ссылку на комнату и отправляет всем ученикам.
3. Дети открывают ссылку, вводят имя и выбирают **одну из десяти свободных ролей**.
4. Когда все готовы (минимум двое), преподаватель нажимает **«Начать партию»**.
5. В свой ход участник при желании использует свою уникальную способность и разыгрывает **одну из трёх карт**. Фишка перемещается по полю.
6. Команда выигрывает, если посетит четыре города, соберёт нужное число искр и каждый сделает хотя бы один ход. Если метель достигнет отметки 10 — проигрыш.

## Правила на поле

- **🎁 Города:** первое посещение доставляет подарок (+2 искры), повторное даёт +1 искру.
- **✨ Искры:** при попадании на клетку +1 искра.
- **🌨️ Метель:** добавляет +1 к метели, если нет щита.
- **📮 Штаб:** +1 искра.
- После полного круга игроков метель усиливается на 1.
- После хода разыгранная карта заменяется новой.
- У каждой роли есть **одна специальная способность на партию**.

## Важно про онлайн-игру

Сайт размещается как статический HTML на GitHub Pages. Для связи между устройствами используется **PeerJS и WebRTC** с публичным сигнальным сервером; отдельный собственный сервер не нужен, но **вкладка ведущего должна оставаться открытой**. Интернет должен разрешать WebRTC-соединения. В некоторых школьных сетях, с VPN или жёстким NAT соединение между участниками может не установиться. Данные игровых комнат не сохраняются на сервере, и перезагрузка вкладки ведущего завершит текущую партию. Игрок может попробовать переподключиться, обновив свою вкладку. Это не замена профессиональному многопользовательскому серверу.

## Учебные связи с ИИ

Названия игровых карт и персонажей помогают вспомнить: промптинг, проверку фактов, качество данных, переобучение модели, робототехнику, информационную безопасность и командную работу. Игра не требует знания терминов, поэтому подходит как новогодний интерактив на занятии без изменения основной программы.
