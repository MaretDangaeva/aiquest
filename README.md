# НейроКвест NEXT · Тетрика · 5–7 классы

Обновлённый самостоятельный браузерный квест на **35–40 минут**. Шесть уровней, карта прохождения, XP, подсказки кошечки Луни. Без установки программ и API-ключей.

## Запуск

**Один файл:** скачайте `НейроКвест_NEXT_5-7_Обновлённая_игра.html` и откройте в браузере. Все игровые изображения встроены в него.

**GitHub Pages:** распакуйте ZIP, загрузите `index.html`, `app.js`, `styles.css` и папку `assets/` в корень нового репозитория. В **Settings → Pages** выберите публикацию из ветки `main`, папка `/(root)`. Новый репозиторий рекомендуется, чтобы не заменить игру для 1–4 классов.

Для тестирования кода: `node test_game.cjs` (нужен Node.js, для игры он не требуется).

## Уровни

1. **ИИ или фото?** Четыре пары изображений. AI-сцены — самостоятельные картины без фрагментов интерфейса; после ответа объясняется происхождение.
2. **Обучи два ИИ.** Перенос навыков к научному и творческому компьютерам. Можно перетаскивать или нажимать карточку и компьютер.
3. **Что умеет ИИ?** Девять ситуаций, включая безопасность: пароли, личные данные, чужие фотографии, проверка фактов.
4. **Собери промпт.** Две иллюстрации (капибара в космическом кафе и парящий город), пять смысловых позиций и много лишних фрагментов; затем эксперимент с изменением запроса.
5. **Разоблачи ложь ИИ.** ИИ уверенно утверждает неверное, игрок выбирает уточняющий вопрос, чтобы разоблачить ошибку. Три случая.
6. **Свой AI-помощник.** Два понятных испытания: учебный наставник и проверяющий факты. Игрок выбирает два правила, запускает тест, улучшает инструкции.

## Важно

Это **игровой учебный симулятор** без подключения к большой нейросети. Иллюстрации подготовлены заранее; «изменение промпта» показывает художественную визуализацию и фильтры, а не новую генерацию. Ответы финального бота моделируются правилами JavaScript. Упражнение с двумя компьютерами объясняет специализацию задач и **не является** реальным обучением модели.

Прогресс сохраняется локально через `localStorage`; никаких персональных данных игра не запрашивает. В конце — поздравление, без диплома.

## Логотип «Тетрика»

В шапке используется **точный URL логотипа, указанный заказчиком:**
`https://tetrika-school.ru/static/new_markup/img/new_logo.svg`

Для просмотра без интернета предусмотрен локальный запасной SVG (`assets/tetrika-logo.svg`). Если официальный сайт блокирует загрузку внешнего изображения, появится запасной вариант. Содержимое SVG с внешнего URL не удалось скачать и встроить автономно из текущей среды.

## Настройка курса

Ссылка на курс задана в `app.js` в переменной `course`: `https://tetrika-school.ru/ai_kids`. Логотип школы в шапке также ведёт на страницу курса ИИ. После этого заново создайте одностраничную версию командой `python build_single.py`.
