# ❄️ Полярная станция — командный ИИ-квест

Новогодний кооперативный квест для 2–10 учеников (5–9 классы). 20–30 минут.

## Как играть
1. Ведущий открывает `index.html` через GitHub Pages и нажимает «Создать комнату».
2. Копирует ссылку из игры и отправляет её всем ученикам.
3. Ученики переходят по **одной и той же ссылке**, нажимают «Присоединиться», вводят имя/ник и выбирают свободную роль.
4. Когда готовы минимум 2 человека, ведущий нажимает «Начать миссию».
5. Команда совместно выполняет четыре задания. Ведущий видит прогресс на общем экране.

## Содержание
- **Радиоволна** — короткая игра на зрительную память и последовательности; у каждого свой фрагмент сигнала.
- **Датасет** — очищаем данные для обучения ИИ (ошибочные метки, дубликаты, персональные данные).
- **Лабиринт** — управляем одним роботом, но каждому игроку доступны только его команды.
- **Запуск** — синхронно передаём энергию по цепочке участников.

Каждый из десяти персонажей имеет специальную одноразовую способность.

## Как устроена совместная игра
- Сайт работает на GitHub Pages. **GitHub Pages сам по себе не синхронизирует игроков.**
- Для связи между устройствами используется WebRTC через библиотеку PeerJS и бесплатный сервис сигнализации PeerJS Cloud. Отдельный сервер или API-ключ не нужен.
- Ведущий — владелец комнаты. Он должен держать страницу открытой на протяжении игры.
- Для подключения нужен интернет. Некоторые школьные сети могут блокировать WebRTC, а бесплатный сервис сигнализации может быть перегружен/недоступен; в таких условиях онлайн-комната не гарантируется.
- Игра не отправляет ответы на сервер хранения и не запрашивает регистрации. Достаточно имени/ника без фамилии.
- Ведущий может перезапустить игру или пропустить этап.

## GitHub Pages
Если файл расположен в `team-quest/index.html` репозитория `aiquest` и публикация GitHub Pages настроена из ветки `main` и папки `/ (root)`, ссылка имеет вид:
`https://maretdangaeva.github.io/aiquest/team-quest/`

Если страница выдаёт 404, проверьте `Settings → Pages → Build and deployment → Deploy from a branch → main / (root)`.

## Для преподавателя
Лучший формат — вывести экран ведущего на проектор, а ученикам дать ссылку на телефоны/ноутбуки. В конце коротко обсудить: почему обучающие данные важны; как организована совместная работа алгоритмов и людей; зачем сверять источники и защищать личные данные.
